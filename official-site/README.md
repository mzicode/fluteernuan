# 即时通信官方网站静态页面

本目录可直接作为静态站点根目录发布，不依赖 Node.js、PHP 或数据库。

## 页面

- 首页：`index.html`
- 技术支持：`support.html`
- 隐私政策：`privacy.html`

## 发布

将本目录中的全部文件和 `assets` 文件夹上传到客户指定的静态站点根目录。

发布后请确认：

1. 三个页面均能通过 HTTPS 直接访问。
2. 桌面端与手机端均可正常浏览，导航和帮助入口可用。

隐私政策内容应在正式上架前由运营方结合生产环境实际启用的第三方 SDK、数据存储地点及业务处理方式进行最终确认。
